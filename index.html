About Reya Risk Matrix

Reya Risk Matrix is an independent, open-source analytics utility designed for Reya Network L2 (Chain ID 1729). It connects directly to public REST node endpoints to provide real-time pricing, risk calculations, and wallet position audits without requiring private keys or wallet signatures.

API Endpoints Utilized:

  • /v2/perpMarketDefinitions
  • /v2/perpMarkets/summary
  • /v2/wallet/{address}/positions
